# General Notes
The `data/` folder contains the sub-folders for the respective language pairs. 
Within these subfolders, jsonl files provide the data needed for the fine-tuning. 
Example files for the "FT_sentences" configurations (Table 7 in our article) for hsb-de and chv-ru can be found in the respective folders.

Please insert the test data files (one file for low-resource language, and one file for high-resource language) in the subfolders which are used for the translation.
